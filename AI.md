# AI Usage

AI tools were used during the development of this project as development assistance.

## Tools Used

- ChatGPT

## What AI Was Used For

AI was used for:

- Structuring the React component
- Improving form validation and state handling
- Reviewing accessibility considerations
- Helping with responsive CSS
- Debugging implementation issues
- Reviewing performance and Lighthouse considerations
- Drafting project documentation

## One Useful Thing AI Helped With

AI helped review the form implementation and identify accessibility requirements such as:

- Proper form labels
- `aria-live` feedback
- `aria-describedby`
- `type="tel"`
- `autocomplete`
- Reduced-motion support

## What AI Got Wrong or What I Changed

Some generated implementation details needed to be reviewed and adjusted manually during development.

I tested the application in the browser and changed the implementation where the generated solution did not match the desired UI or assignment requirements.

## What I Personally Reviewed

I personally reviewed and tested:

- The complete user flow
- Form validation
- Loading state
- Success state
- Error state
- Claim code display
- Copy-to-clipboard interaction
- Responsive layout
- Accessibility behavior
- Production build
- Lighthouse results

The final implementation was tested locally and after deployment.
